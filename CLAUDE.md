# Genpact Integration — Claude Code Context

This project automates a **code→Figma→code round-trip** for Genpact's Design System, built on KendoReact primitives. Raw Kendo-9 components are authored in this repo's Storybook, mirrored 1:1 into Figma, branded by a designer in Figma, then synced back to code as a global Kendo theme override.

> **Direction:** This supersedes the project's earlier one-way Figma→Storybook flow. See `docs/adr/0001-code-to-figma-round-trip.md` for the decision and rejected alternatives, and `CONTEXT.md` for canonical terms. The v2 plan lives in `v2.md`.

## Project Structure

- `src/components/` — raw Kendo-9 wrapper components (one folder per component)
- `src/stories/` — Storybook story files (`.stories.tsx`, one per component)
- `src/theme/kendo-overrides.css` — single global Kendo theme override; where step-4 branding lands
- `CONTEXT.md` — canonical domain terms (round-trip, raw KendoReact primitive, branding)
- `docs/adr/` — architecture decision records (`0001` = the round-trip reorientation)
- `v2.md` — the v2 plan that drives the reorientation
- `DESIGN.md` — Genpact brand tokens (generated by `/ds-extract-design`, run once)
- `REQUIREMENTS.md` — design standards and quality acceptance criteria
- `KENDOREACT_COMPONENTS.md` — reference: Figma visual patterns → KendoReact component API
- `.storybook/preview.ts` — imports the KendoReact Default theme + `kendo-overrides.css` globally

## Skills

### Round-trip skills (planned — v2)

The round-trip is automated by three skills, mapping to the three automatable steps. **These are not built yet** — they are the v2 work.

1. **`/kendo-storybook-scaffold`** — generate N raw Kendo-9 wrappers + CSF3 stories with full `argTypes` for each component's prop axes. (step 1)
2. **`/kendo-to-figma`** — faithful 1:1 mirror of a raw component into a sandbox Figma file via the Figma MCP code-to-design. (step 2)
3. **`/figma-to-kendo`** — read the polished Figma component → sync brand tokens into `src/theme/kendo-overrides.css` → regenerate/verify branded stories → flag structural drift. (step 4)

New skills are written for this repo, borrowing *patterns* (not code) from `tidy-dev-team/kido-ds-skills-automation`.

### `/ds-extract-design`

Kept. One-time extraction of Genpact brand tokens from the Figma foundation file into `DESIGN.md` — the source of branding values for step 4.

### `/genpact-figma-to-storybook` — RETIRED

The old one-way Figma→Storybook generator. Superseded by `/figma-to-kendo` (which uses the global-theme model, not per-component wrappers). Definition kept at `skills/genpact-figma-to-storybook.md` for reference only.

## Conventions

- Story files: `.stories.tsx` (never `.ts` — Vite requires TSX extension for JSX)
- Story format: CSF3 with `satisfies Meta<typeof X>` and `StoryObj<typeof meta>`
- All interactive elements must use KendoReact components (never raw HTML inputs)
- Brand tokens: `#15223F` text, `#104683` primary blue, `#C1CBE1` border, `#E3E7EF` filter bg
- Font: Rubik (Light 300, Regular 400), base 12px
